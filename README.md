# dexbury.com

Website of Dexbury Group SRL: Consulting · Coaching & Training · Executive Search · Ventures.

- Static site, no build step. Netlify publishes the repository root (see `netlify.toml`).
- Every push to `main` deploys to production at https://www.dexbury.com.
- Brand fonts (Sen, Lexend Deca, SIL OFL 1.1) are self-hosted in `assets/fonts/`.
